# VAIGA – Events & Experiences (projectafspraken)

- Communicatie met de gebruiker in het Nederlands. De website is geschreven in het Engels en heeft een taalmenu met vlaggen EN(UK-vlag)/PT/ES/NL (besluit 2026-11-18; vlaggen in `assets/img/flags/`): `assets/js/i18n.js` (in de head van elke pagina; taalkeuze onthouden in localStorage, adres blijft schoon: `?lang=xx` alleen in gedeelde links, wordt na lezen uit de adresbalk gehaald; alleen als de browser niets kan onthouden gaat `?lang` mee in de links) vervangt de Engelse teksten via `assets/i18n/translations.js` ("Engelse tekst": [pt, es, nl]). - VAIGA is een **apart project**, volledig los van Latinpulse (eigen map `Documents\vaiga`, eigen repository). Latinpulse is één van de eventconcepten binnen VAIGA (schrijfwijze: "Latinpulse", kleine p).
- Techniek: uitsluitend HTML, CSS en vanilla JavaScript. Geen React, Next.js of andere frameworks, geen bouwstap. Geschikt voor GitHub Pages + domein vaiga.eu (`CNAME`). `index.html` in de root.
- Publicatie: live op https://vaiga.eu via GitHub Pages, repo `LatinpulseAlgarve/VAIGA-Events-Experiences` (openbaar), branch `main` (beschermd: wijzigen via branch + pull request, na akkoord van de gebruiker). `CNAME` = `vaiga.eu`, absolute adressen naar vaiga.eu. DNS bij OVH; MX/SPF (e-mail info@vaiga.eu) nooit aanraken.
- Werkwijze wijzigingen: nieuwe branch → wijzigen → `tools\check-site.ps1` ALL OK → visueel telefoon + laptop → akkoord gebruiker → PR samenvoegen → live controleren (alle pagina's 200, telefoon/tablet) → pas dan "klaar".

Servercontrole (besluit gebruiker 2026-11-19): contact.js stuurt naar `formGateway` in config.js = Cloudflare Worker `vaiga-forms` (`https://vaiga-forms.latinpulse.workers.dev/send`, code in `tools/cloudflare-worker/vaiga-forms.js`, door de gebruiker in het Cloudflare-dashboard geplakt). De Worker controleert het Turnstile-token bij Cloudflare (siteverify; secret `TURNSTILE_SECRET` alleen in de Worker, nooit in de repo) + Origin/hostname vaiga.eu, en stuurt pas dan alleen de bekende velden door naar FormSubmit (optionele secret `FORM_ENDPOINT` = FormSubmit-alias). Worker-adres staat ook in CSP `connect-src` van contact.html en plan.html. Wijzig je de Worker-code, dan moet de gebruiker hem opnieuw plakken/deployen. `tools\check-site.ps1` staat alleen deze Cloudflare-bron toe.
