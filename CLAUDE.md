# VAIGA – Events & Experiences (projectafspraken)

- Communicatie met de gebruiker in het Nederlands; de website zelf in het Engels (internationaal merk).
- VAIGA is een **apart project**, volledig los van Latinpulse (eigen map `Documents\vaiga`, eigen repository). Latinpulse is één van de eventconcepten binnen VAIGA (schrijfwijze: "Latinpulse", kleine p).
- Techniek: uitsluitend HTML, CSS en vanilla JavaScript. Geen React, Next.js of andere frameworks, geen bouwstap. Geschikt voor GitHub Pages + domein vaiga.eu (`CNAME`). `index.html` in de root.
- Publicatie: live op https://vaiga.eu via GitHub Pages, repo `LatinpulseAlgarve/VAIGA-Events-Experiences` (openbaar), branch `main` (beschermd: wijzigen via branch + pull request, na akkoord van de gebruiker). `CNAME` = `vaiga.eu`, absolute adressen naar vaiga.eu. DNS bij OVH; MX/SPF (e-mail info@vaiga.eu) nooit aanraken.
- Werkwijze wijzigingen: nieuwe branch → wijzigen → `tools\check-site.ps1` ALL OK → visueel telefoon + laptop → akkoord gebruiker → PR samenvoegen → live controleren (alle pagina's 200, telefoon/tablet) → pas dan "klaar".
- Community (besluit 2026-11-18): dezelfde opzet als de Latinpulse-community (feed, reacties + 1 niveau antwoorden, melden, Meet & Go alleen bij VAIGA-events op een openbare plek). NOOIT: likes/tellers, privéberichten, ledenzoeker, profielen, vriendschapsverzoeken, matching, openbare deelnemerslijsten. Nu alleen een VOORBEELD met verzonnen inhoud: `community-preview-fb199926e479.html` (noindex, niet in menu/sitemap, niets opgeslagen; `assets/community/community.js` + `community-demo.js` + `community.css`). Let op: de repo is openbaar, dus die "geheime" link is vindbaar; daarom alleen fictieve inhoud. De echte community heeft een server nodig (bijv. WordPress-plug-in op community.vaiga.eu) + juridische check; niet zonder toestemming bouwen/publiceren.
- Latin Parties = samenwerking Latinpulse Algarve × Tropicaliente (banner tot er een gezamenlijke foto is; partnerknoppen onder de tekst). `latinpulseUrl` in config.js = Facebook-groep tot de Latinpulse-website online is. Latinpulse Algarve staat NIET meer op de partnerpagina (besluit 2026-11-18).
- Grote afbeeldingsvlakken (`.frame`) zijn 1080×450; alleen de eventdetailfoto houdt 16:10. Uitzondering conceptenpagina (besluit 2026-11-18): alle conceptafbeeldingen vierkant 360 px (telefoon max 300 px), ongeveer zo hoog als de tekst ernaast. Elke pagina heeft een "naar boven"-knop (`.to-top`, gemaakt in main.js). E-mail info@vaiga.eu als knop (vaiga.com is NIET van VAIGA: staat te koop).
- Social media in config.js leeg = "coming soon"-knoppen.
- Beveiliging: CSP + referrer-policy als `<meta>` op elke pagina; geen inline scripts/`on…=`-attributen; externe links `rel="noopener"`.
- **Niets automatisch publiceren.** Niet naar GitHub pushen of een repository aanmaken zonder uitdrukkelijke toestemming.
- Geen bestaande bestanden verwijderen zonder toestemming.
- **Geen fictieve evenementen, datums, prijzen of contactgegevens.** Ontbrekende informatie = zichtbare placeholder (`<span class="placeholder-note">[...]</span>` of lege waarde in `config.js`). Voorbeeld-events alleen in `VAIGA_PREVIEW_EVENTS`, zichtbaar met `?preview=1` (gele banner).
- Gegevens: `assets/data/events.js` (evenementen), `assets/data/categories.js` (concepten, onbeperkt uitbreidbaar), `assets/js/config.js` (contact, social, formulierdienst).
- Huisstijl in `assets/css/vaiga.css` (tokens in `:root`). Header-banner `assets/img/header-800/1400/2172.jpg` bovenaan elke pagina (bron: ChatGPT-afbeelding van de gebruiker). Logo gebaseerd op die header: `logo.svg` (compact, menubalk), `logo-full.svg` (met tagline, footer), icoon `icon.svg` (+ png 180/512), deelafbeelding `og-image.jpg` (1200×630).
- Na elke wijziging: `tools\check-site.ps1` draaien en pas "klaar" melden bij **ALL OK**; daarnaast visueel controleren op telefoon (390 px) en laptop.
- Fonts niet van Google-servers laden (privacy); eigen merkletter alleen self-hosted en pas na toestemming downloaden.
